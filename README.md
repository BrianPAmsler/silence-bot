Simple bot to play random sounds in your voice calls.

Permissoins are not secure and i'd advise against giving them to anyone you don't 100% trust.<br>
Anyone with permissions can give other people permissions, so be careful.<br>
Also there are very likely some bugs or general usability issues that I don't really care to fix.<br>
Sounds are stored uncompressed as base64 strings in json files, so I'd advise not increasing the 10s sound file limit.

I made this in 2 days so use at your own risk.

Requires FFMPEG to be installed
